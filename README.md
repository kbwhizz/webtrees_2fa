# 🚀 Two Factor Authentication for Webtrees 2


Add two-factor authentication to Webtrees to keep your data more secure.


## ✨ Features

1. Works out of the box with Google Authenticator.
2. Adds a 2fa link to the menu (allowing you to set it up by scanning a QR code)
3. Supplies the 2fa code box on the same page as the username/password, once activated
4. Locks for a 5 minutes after 5 failed code entry attempts to avoid abusive machine use etc.

## 🚀 Getting Started

Install as a webtrees module
