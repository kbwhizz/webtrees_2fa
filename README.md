# 🚀 Two Factor Authentication for Webtrees


Add two-factor authentication to Webtrees to keep your data more secure.


## ✨ Features

– Works out of the box with Google Authenticator.
– Adds a 2fa link to the menu (allowing you to set it up by scanning a QR code)
– Supplies the 2fa code box on the same page as the username/password, once activated
- Locks for a few minutes after 5 failed code entry attempts to avoid BOTs etc.

## 🚀 Getting Started

Install as a webtrees module
